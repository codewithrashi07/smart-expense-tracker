# Contributing to Smart Expense Tracker

Thanks for your interest in contributing! We welcome contributions of all kinds — bug reports, feature requests, documentation fixes, and code improvements.

How to contribute

1. Fork the repository and create a branch for your change:
   - git clone https://github.com/codewithrashi07/smart-expense-tracker.git
   - git checkout -b feature/short-description or bugfix/short-description

2. Open an issue first for major changes or feature requests so we can discuss the approach.

3. Make incremental, well-scoped commits with clear messages. Follow the existing code style and formatting.

4. Add or update tests where relevant. Ensure all existing tests pass locally.

Pull request process

- Push your branch to your fork and open a Pull Request (PR) against the `main` branch of this repository.
- In your PR description, explain the problem, your solution, and any steps to test.
- PRs should be small and focused. Large changes may be split into multiple PRs.
- A maintainer will review your PR and may request changes. Please respond to review comments.

Code style

- Follow the repository's existing style. If using JavaScript/Node, run any provided linters (eslint) and formatters (prettier) before committing.

Tests

- Add tests for bug fixes and new features.
- Run the test suite locally and ensure no new failures are introduced.

Communication

- Use issues for discussion and PRs for code changes.
- Be respectful and constructive in code reviews and comments.

Thanks for helping improve Smart Expense Tracker — your contributions are appreciated!
